# Lead Monitor

Company and product information website for NEW SOLUTIONS DOO.

Live site: https://michael-rublev.github.io/lead-monitor/

Static HTML, CSS and JavaScript, with English and Russian content. Pages: home, privacy policy, data deletion instructions. Threads integration is under development; this site does not implement OAuth or live search.

Published with GitHub Pages from the main branch, repository root. Paths use the /lead-monitor/ project prefix. Only public website files belong in this repository. Do not add company scans, API tokens or private monitor data.
